# Nexa Studio

A responsive, multi-page portfolio for an independent digital design and development studio. Explore the studio's approach, services, exploratory project concepts, and an interactive project-brief builder.

Nexa is presented as a design and development service, not a downloadable app or SaaS product. Projects shown on the Work page are clearly identified as concepts rather than client work. The contact form runs entirely in the browser: it prepares a project brief that can be copied or downloaded, but does not send or store submissions.

## Pages

- `index.html` — Studio overview and featured concepts
- `about.html` — Studio approach and working principles
- `services.html` — Digital direction, websites and products, and product foundations
- `work.html` — Filterable concepts with interactive project details
- `contact.html` — Project brief builder and frequently asked questions

## Built with

- HTML
- CSS, including responsive layouts, reduced-motion support, and page transitions
- Vanilla JavaScript for navigation, motion, concept filters and details, and the local project-brief builder

## Run

Open `index.html` in a browser, or use a local server such as VS Code Live Server to try the multi-page navigation and browser features.
