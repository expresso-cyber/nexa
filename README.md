# Nexa Studio

A responsive single-page portfolio for an independent digital design and development studio. It explains Nexa's services, shows sample project concepts, outlines the project process, and invites prospective clients to get in touch.

Nexa is presented as a service business, not as a downloadable app or SaaS product. The contact form is a front-end demo; it does not send or store submissions until connected to a backend.

## Built with

- HTML
- CSS, including responsive layouts and motion effects
- Vanilla JavaScript for navigation, project filters, scroll reveals, and form feedback

## Run

Open `index.html` in a browser, or use a local server such as VS Code Live Server.
